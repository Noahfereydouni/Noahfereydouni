### Projects

**[pd-snrnaseq-discovery-validation](https://github.com/Noahfereydouni/pd-snrnaseq-discovery-validation)**

A two-cohort single-nucleus RNA-seq study of Parkinson's disease. Candidate markers were
nominated by independent re-analysis of one public postmortem cohort, then tested for
replication in a second. Two of five replicated: NEAT1 in astrocytes and MOBP in
oligodendrocytes. The dopaminergic candidates did not, and one could not be tested. The
repository holds the analysis scripts, the differential expression exports behind every
reported table, and a written reconciliation of code against manuscript text.

Preprint: [10.5281/zenodo.22172961](https://doi.org/10.5281/zenodo.22172961)
`R` `Seurat` `Harmony` `DESeq2` `clusterProfiler` `scDblFinder`

**[sc-qc-report](https://github.com/Noahfereydouni/sc-qc-report)**

Point it at a 10x filtered matrix folder and it writes one self-contained HTML report
saying whether the sample is worth analysing. Six metrics, each with a violin and a
histogram and a plain language reading of what the number means, plus a verdict at the
top. The thresholds are the usual 10x rules of thumb and the report says so, because a
cutoff that suits PBMCs is wrong for heart or kidney.

`Python` `scanpy` `Scrublet` `matplotlib`

**AI-assisted literature capture tool** (private)

A Python pipeline applying a focus-count NLP approach to about a thousand publications and
a decade of ISSCR abstract books from 2012 to 2024, tagging keywords automatically to trace
how research attention shifts over time.
