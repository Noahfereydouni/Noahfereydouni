### Current work

**[pd-snrnaseq-discovery-validation](https://github.com/Noahfereydouni/pd-snrnaseq-discovery-validation)**
A two-cohort single-nucleus RNA-seq study of Parkinson's disease: candidate markers
nominated by independent re-analysis of one public postmortem cohort, then tested for
replication in a second. Astrocyte and oligodendrocyte signatures replicated; the
dopaminergic and microglial candidates did not. The repository contains the full analysis
pipeline, the differential expression exports behind every reported table, and a written
reconciliation of code against manuscript text.

*R · Seurat · DESeq2 · clusterProfiler · Harmony · scDblFinder*

**AI-assisted literature capture tool**
A Python pipeline applying a focus-count NLP approach to ISSCR abstract books (2012–2024),
automating keyword tagging across a decade of conference proceedings to trace how research
attention shifts over time.
